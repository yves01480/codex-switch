INSTALL

兩個步驟完成安裝

預設建立 2 個 profile。把 2 改成你需要的數量，支援 1–99。

Terminal 
curl -fsSL https://install.cruxilion.com/cruxilion-codex.sh -o /tmp/cruxilion-codex.sh
sh /tmp/cruxilion-codex.sh --accounts 2
export PATH="$HOME/.local/bin:$PATH"
codex1 login
codex2 login
01

各自登入

codex1 login、codex2 login 分別登入自己的帳號。

02

各自執行

codex1、codex2 resume 可以同時執行，彼此資料目錄隔離。

03

隨時擴充

使用 codex-switch add codex3 新增下一個 profile。

WHY

不是切換 token，
而是隔離 profile。

獨立 CODEX_HOME每個 profile 有自己的設定、session 與登入狀態。
不碰登入憑證工具不讀取、不複製、不上傳，也不解析 auth.json。
保留既有帳號可採用既有 ~/.codex 與 ~/.codex-personal，不搬移憑證。
安全移除remove 只停用；只有明確執行 purge ... --yes 才可能刪除工具建立的 profile。
